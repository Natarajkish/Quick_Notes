# 📝 QuickNotes - Firebase Cloud Note-Taking App

QuickNotes is a lightweight, real-time note-taking web application built using **HTML**, **CSS**, **JavaScript**, and **Firebase Firestore**. It allows users to add and delete notes, with all updates reflected in real-time using Firebase’s powerful cloud infrastructure.

---

## 🚀 Features

- ✅ Add text notes through a simple UI
- 🔄 Real-time data synchronization with Firebase Firestore
- ❌ Delete notes by clicking on them
- 🌐 Serverless architecture (no backend required)
- 💡 Educational and beginner-friendly codebase

---

## 🧰 Tech Stack

| Technology   | Purpose                        |
|--------------|--------------------------------|
| HTML         | Structure of the web page      |
| CSS          | Styling and layout             |
| JavaScript   | Front-end logic                |
| Firebase     | Real-time database and hosting |
| Firestore    | Cloud NoSQL database           |
